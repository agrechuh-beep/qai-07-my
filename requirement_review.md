## Purpose
Выполнять систематический анализ требований перед их использованием для формирования задач
для разработки и проектирования тестовых сценариев.

Skill предназначен для выявления содержания требований, их структуры и формата, неоднознчностей, противоречий, 
зависимостей и недостатка информации

## Input
- текст требований
- свзанные бизне сценарии
- критерии приемки
- ссылки на вложенные требования

Skill не может самостоятельно искать отсутсующие входные данные за пределами входного контекста

## Procedure:
При анализе требований необходимо:
- определить функциональные требования
- выделить бизнес-правила
- выявитьограничения
- определить критерии приемки
- определить зависиости
- выявить неоднозначности
- выявить противоречия
- выявить недостатки информации

## Rules
При выполнении анализа необходимо соблюдать следущие правила:
- не добавлять отсутсующие данные
- не выдвать предположения за подтвержденые требования
- не изменять требования
- не выполнять действия, не относящиеся к анализу требований

## Output
Результат выполнения sklill должен содержать:
- список выявленныз функциональных требований
- бизнес правила
- огрничения
- зависимости
- критерии приемки
- выявленные неоднозначности
- выявденные противоречия
- выявленные недостатки информации
- выявленные риски

Результат должен быть струтурирован так, что бы следующий этап мог его использовать без повторного анализа

## Completion Criteria
skill считается успешно выполненным, если:
- входные требования проанализиролваны
- бизне правила зафиксированы
- результат не содержит выдуманных требований
- сформирован структурированный результат
