# SRS: управление печатью документов (v1.2)

**Статус:** согласовано
**Владелец:** продуктовая команда

## 1. Назначение

Сервис печати принимает документы от внешних систем и передаёт их на печатающее устройство,
фиксируя результат каждой операции.

## 2. Функциональные требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-1 | Система принимает документ на печать по идентификатору и возвращает код операции | Высокий |
| FR-2 | Система передаёт документ на печатающее устройство и фиксирует время начала и окончания печати | Высокий |
| FR-3 | При успешной печати система возвращает код результата `0`; при ошибке — код из перечня ошибок | Высокий |
| FR-4 | Система хранит историю операций печати не менее 90 суток | Средний |
| FR-5 | Система ограничивает размер принимаемого документа 20 МБ | Средний |

**Критерии приёмки:**

- FR-1: при передаче корректного документа API возвращает код операции в течение 2 секунд.
- FR-2: при успешной печати в истории появляется запись с временем начала и окончания.
- FR-3: при успешной печати API возвращает код `0`; при недоступности устройства — код `14`.
- FR-4: записи старше 90 суток удаляются плановой задачей.
- FR-5: документ размером более 20 МБ отклоняется с кодом `7`.

## 3. Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-1 | Время отклика API на приём документа — не более 2 секунд в 95 % запросов |
| NFR-2 | Сервис доступен 99,5 % времени в месяц |
| NFR-3 | Все операции печати журналируются без содержимого документа |

## 4. Бизнес-правила

- BR-1: печать доступна только авторизованным пользователям с правом `print.execute`.
- BR-2: документ, отклонённый из-за размера, повторно не печатается автоматически.

## 5. Ограничения и зависимости

- Ограничение: устройство печати одно на инсталляцию.
- Зависимость: сервис аутентификации, выдающий право `print.execute`.

## 6. Вне области (Out of scope)

- Формирование документов.
- Сканирование и копирование.
