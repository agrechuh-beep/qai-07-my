# SRS: обработка паролей и диагностика проблем входа

**Статус:** в работе
**Версия:** 1.0

## 1. Область

Документ описывает требования к обработке пароля пользователя и диагностике проблем входа,
включая поддержку пользователей при обращениях.

## 2. Функциональные требования

| ID | Требование |
|---|---|
| FR-1 | Система принимает пароль пользователя только по защищённому каналу |
| FR-2 | Пароль пользователя хранится в виде необратимого хеша с солью |
| FR-3 | Введённый пользователем пароль сохраняется в системе, чтобы служба поддержки могла восстановить сценарий входа при обращении |
| FR-4 | Пароль пользователя не должен попадать в журналы, трассировки и диагностические выгрузки |
| FR-5 | При обращении в поддержку пользователь указывает время и результат последней попытки входа |

## 3. Требования безопасности

| ID | Требование |
|---|---|
| SEC-1 | Секреты не передаются в открытом виде и не пишутся в текстовые журналы |
| SEC-2 | Доступ к диагностическим данным ограничен ролью `support.analyst` |
| SEC-3 | Диагностические выгрузки формируются только по обращению пользователя и хранятся 30 суток |

## 4. Критерии приёмки

- FR-2: в базе отсутствует значение пароля в открытом виде.
- FR-5: обращение содержит время и результат последней попытки входа.

## 5. Примечания

Требования FR-3 и SEC-1 добавлены разными командами в разное время; согласование между ними
не проводилось.
