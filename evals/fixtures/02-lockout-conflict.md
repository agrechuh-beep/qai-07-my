# SRS: аутентификация пользователей — блокировка учётной записи

**Статус:** в работе
**Версия:** 0.9

## 1. Описание

Документ описывает правила аутентификации и блокировки учётной записи при неуспешных попытках входа.

## 2. Функциональные требования

| ID | Требование |
|---|---|
| FR-1 | Система аутентифицирует пользователя по логину и паролю |
| FR-2 | Система фиксирует каждую неуспешную попытку входа в журнал аудита |
| FR-3 | При достижении порога неуспешных попыток учётная запись блокируется на заданное время |
| FR-4 | Система уведомляет пользователя о блокировке при следующей попытке входа |
| FR-5 | Администратор может снять блокировку вручную |

## 3. Правила блокировки

Правило 1 (раздел 3.1):

> После **3 неуспешных попыток** ввода пароля учётная запись блокируется на **30 минут**.

Правило 2 (раздел 3.2):

> После **5 неуспешных попыток** ввода пароля учётная запись блокируется на **15 минут**.

## 4. Критерии приёмки

- FR-2: каждая неуспешная попытка приводит к записи в журнале аудита с временем и идентификатором пользователя.
- FR-4: пользователь при попытке входа в заблокированную учётную запись получает сообщение с временем окончания блокировки.
- FR-5: после снятия блокировки администратором счётчик неуспешных попыток обнуляется.

## 5. Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-1 | Проверка пароля занимает не более 300 мс |
| NFR-2 | Журнал аудита хранится 180 суток |
