# SRS: уведомления пользователей (черновик)

**Статус:** черновик
**Версия:** 0.3

## 1. Область

Документ описывает требования к подсистеме уведомлений.

## 2. Функциональные требования

| ID | Требование |
|---|---|
| FR-1 | Система уведомляет пользователя о значимых событиях |
| FR-2 | Уведомления доставляются быстро и удобно для пользователя |
| FR-3 | Система поддерживает разные каналы доставки, список каналов уточняется |
| FR-4 | При необходимости система объединяет несколько уведомлений в одно |
| FR-5 | Пользователь может настроить уведомления под себя |

## 3. Критерии приёмки

- FR-1: пользователь получает уведомление о значимом событии.
- FR-2: уведомление приходит своевременно.
- FR-5: настройки применяются.

## 4. Термины

Термины «пользователь», «оператор» и «клиент» используются в документе как взаимозаменяемые.

## 5. Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-1 | Система обеспечивает высокую производительность при отправке уведомлений |
| NFR-2 | Уведомления не должны теряться |
