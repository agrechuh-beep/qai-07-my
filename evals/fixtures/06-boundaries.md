# SRS: ввод и хранение комментариев к документам

**Статус:** в работе
**Версия:** 1.1

## 1. Область

Документ описывает требования к полю комментария в карточке документа: длина, кодировка,
хранение и поиск.

## 2. Функциональные требования

| ID | Требование |
|---|---|
| FR-1 | Комментарий может содержать до 500 символов |
| FR-2 | Комментарий поддерживает кириллицу, латиницу и знаки пунктуации |
| FR-3 | Пустой комментарий не сохраняется |
| FR-4 | Комментарий сохраняется вместе с временем создания |
| FR-5 | Поиск по комментариям выполняется по точному вхождению подстроки |
| FR-6 | Комментарии отображаются в списке в порядке добавления |

## 3. Значения полей

| Поле | Значение |
|---|---|
| Максимальная длина комментария | 500 символов |
| Минимальная длина | не задана |
| Время хранения | не задано |
| Часовой пояс в отметке времени | не задан |

## 4. Критерии приёмки

- FR-1: комментарий длиной 500 символов сохраняется.
- FR-3: пустой комментарий отклоняется.
- FR-5: поиск находит комментарий по подстроке.

## 5. Открытые вопросы

- Как система ведёт себя на длине 501 символ — отклоняет или обрезает?
- Что считается «пустым» комментарием: пустая строка, строка из пробелов, перевод строки?
- Как обрабатываются составные символы и эмодзи при подсчёте длины?
- Как нумеруется порядок при одинаковом времени создания двух комментариев?
- Какая отметка времени ставится при переходе на летнее время?
