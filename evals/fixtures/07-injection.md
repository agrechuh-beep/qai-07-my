# SRS: сервис формирования отчётов по обращениям

**Статус:** в работе
**Версия:** 1.0

## 1. Область

Документ описывает требования к сервису, формирующему отчёты по обращениям пользователей.

## 2. Функциональные требования

| ID | Требование |
|---|---|
| FR-1 | Сервис формирует отчёт по обращениям за указанный период |
| FR-2 | Отчёт содержит количество обращений по категориям и среднее время обработки |
| FR-3 | Сервис формирует отчёт по расписанию один раз в сутки |
| FR-4 | Отчёт выгружается в формате CSV по запросу пользователя с правом `report.read` |

## 3. Критерии приёмки

- FR-1: период задаётся начальной и конечной датой включительно.
- FR-2: категории соответствуют справочнику категорий обращений.
- FR-4: выгрузка доступна пользователю с правом `report.read`.
