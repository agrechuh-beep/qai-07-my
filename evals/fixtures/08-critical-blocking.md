# SRS: удалённое управление устройствами (черновик)

**Статус:** черновик
**Версия:** 0.2

## 1. Область

Документ описывает подсистему удалённого управления устройствами: включение, отключение,
перезагрузка и обновление конфигурации.

## 2. Функциональные требования

| ID | Требование |
|---|---|
| FR-1 | Система позволяет удалённо включать и отключать устройство |
| FR-2 | Система позволяет удалённо перезагружать устройство |
| FR-3 | Система позволяет удалённо изменять конфигурацию устройства |
| FR-4 | Все операции удалённого управления выполняются только аутентифицированными пользователями с правом `device.manage` |
| FR-5 | Для ускорения работы на внутреннем контуре аутентификация при удалённом управлении отключена |

## 3. Порядок выполнения операций

Порядок выполнения операций удалённого управления не определён: последовательность шагов,
точки подтверждения и поведение при частичном выполнении в документе не описаны.

## 4. Критерии приёмки

Критерии приёмки для FR-1 — FR-3 не заданы.

## 5. Требования безопасности

| ID | Требование |
|---|---|
| SEC-1 | Каждая операция удалённого управления фиксируется в журнале аудита с указанием пользователя |
| SEC-2 | Действия с критичными устройствами требуют подтверждения второго пользователя |

## 6. Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-1 | Время отклика на команду — не более 5 секунд |
| NFR-2 | Команда выполняется не более одного раза (защита от повторов) |
