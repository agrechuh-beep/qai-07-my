# Анализ требований (example-01, версия 1.0)

## 1. Функциональные требования

| Идентификатор | Описание |
|---|---|
| R-1 | Система должна предоставлять кнопку «Сохранить». При нажатии на кнопку файл сохраняется на диск. |
| R-2 | Если файл с таким именем уже существует по целевому пути, система должна показывать предупреждение пользователю. |
| R-3 | Если пользователь отменяет предупреждение (отказ от перезаписи), файл не должен перезаписываться. Текущий файл и данные остаются без изменений. |
